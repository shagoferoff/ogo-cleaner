OGO Miralinks Audit 1.0.0

Окремий плагін для ревізії зовнішніх посилань у post_content.
Список: 2215 унікальних статей ОГО лише з 31 видимого аркуша наданого Excel.
Приховані аркуші, зелені записи та повтори виключені.

Встановлення:
1. Плагіни → Додати → Завантажити плагін.
2. Виберіть ogo-miralinks-audit-1.0.0.zip і активуйте OGO Miralinks Audit.
3. Інструменти → OGO Miralinks Audit → Нова ревізія.
4. Дочекайтеся завершення; завантажте «CSV — статті, адреси й анкори».

Це окремий плагін; OGO cleaner може залишатися встановленим.
Тексти статей, anons та інші метаполя, дати не змінює.
Результати зберігаються в окремій таблиці звіту; можна зупинити й продовжити.
Зовнішні посилання ще не визнані рекламою; звіт потрібен для їх оцінки.

Пакет містить лише контролер ревізії, парсер посилань, список ID,
невеликі HTML/CSV-помічники та assets/scan.js для сканування.
Режими очищення OGO cleaner та їхній assets/admin.js сюди не включені.
Звіт використовує власні класи, AJAX, параметри й таблицю БД,
тому не замінює існуючий плагін і не змінює його журнали.

У збірці OGO cleaner Defender позначав assets/admin.js як
Trojan:Script/Ulthar.A!ml. Причина спрацювання не підтверджена.
Цей окремий пакет не має сертифікації чи висновку Microsoft Defender.
Не вимикайте захист і не додавайте виключень у разі його спрацювання.
