# Рівненська газета — підписи джерела, 1.29.0

Нова операція `gazeta_sources` у меню OGO cleaner. Доступ адміністратора
і редактора залишається як у 1.28.0. Наявний режим `gazeta` для контактних
блоків не змінено: підписи джерела обробляються окремо.

Обидва наведені редакцією варіанти:

```html
За матеріалами <a href="http://gazeta.rv.ua/">"Рівненської газети"</a>
За матеріалами <a href="http://gazeta.rv.ua/articles/view/2011-06-16/17243.html">"Рівненської газети"</a>
```

дають однаковий текст:

```text
За матеріалами "Рівненської газети"
```

Збіг визначається за точним доменом gazeta.rv.ua/www.gazeta.rv.ua, фразою
«За матеріалами» безпосередньо перед посиланням і назвою «Рівненської газети»
в самому посиланні. Підтримує http/https/`//`, будь-який шлях і параметри URL.
Дати/ID старого сайту не використовуються, HTTP-запитів немає.

Знімає тільки відкривальний і закривальний теги a. Інші байти не змінює:
слова, лапки (включно з HTML-сутностями), вкладене просте текстове оформлення,
пробіли, переноси, зовнішні p/div, Gutenberg-коментарі й інші посилання.
Лапки можуть бути всередині або навколо посилання. Пробіли/NBSP, регістр,
двокрапка, inline-оформлення фрази «За матеріалами» не заважають.

Звичайні посилання на газету без такої фрази не обробляються й не блокують
готовий підпис у тому самому матеріалі. Інший домен, зокрема gazeta.ogo.ua,
не належить цій операції. Межі домену перевіряються, облікові дані в URL
не підтримуються. Фраза не переноситься через межу p/div/іншого блоку,
порожній рядок, коментар або захищений блок коду.

Коментарі, script/style/textarea/pre/code та фальшиві a всередині атрибутів
пропускаються. Вкладені/незакриті посилання, невпізнана назва, медіа або складне
оформлення в кандидатові залишаються для перевірки. Якщо хоч один кандидат
потребує перевірки, матеріал не переходить у ready для масового застосування.
Часткову пропозицію можна побачити в попередньому перегляді.

Операція користується звичайним журналом before/after, резервними знімками,
nonce, блокуванням, edit_others_posts для доступу й edit_post для кожної зміни,
атомарною перевіркою початкового контенту та відкатом. Область post_content,
типи/статуси сканування стандартні для OGO cleaner; anons не читається/не змінюється.

Порядок роботи: оновити плагін → вибрати «Рівненська газета — підписи джерела» →
«Нове сканування» → перевірити «Було → стане» → застосувати вибрані або готові
матеріали. Після очищення/відкату очистити кеш сайту та CDN за потреби.

Перевірки: `tests/gazeta-sources.php` містить обидва приклади, варіанти адрес,
лапок і оформлення, захищений вміст, неоднозначність та повторний запуск.
`tests/gazeta-sources-wordpress.php` перевіряє справжні scan/apply/restore під
редактором, незмінність anons/контактних блоків/інших посилань, ручні випадки,
повторне сканування й конфлікт із пізнішою редакторською правкою. Тільки
ізольована БД ogo_audit_test з активованим плагіном і користувачем audit_admin.
