# Доступ для редакторів

OGO cleaner 1.28.0 та OGO Miralinks Audit 1.1.0 відкривають інструмент
користувачам зі стандартним WordPress-правом `edit_others_posts`.
За стандартними ролями це адміністратори й редактори. Користувацькі ролі
з таким самим правом також мають доступ. Автори, учасники, підписники та
гості не мають доступу навіть через прямий URL, AJAX або CSV-експорт.

Адміністратор встановлює відповідне оновлення й призначає новому працівнику
роль **Редактор**. Інструмент доступний у меню **Інструменти → OGO cleaner**
або **Інструменти → OGO Miralinks Audit** для окремого плагіна ревізії.
Додаткового налаштування ролей чи нового права не потрібно.

Доступ поширюється на сторінки, журнали, попередній перегляд, запуск/продовження
сканувань, очищення й відкат у повному плагіні, ревізії та CSV-експорт.
У read-only режимах функцій очищення не додано. Редактор отримує доступ до
загальних звітів інструменту; звіти не є приватними для автора запуску.

Права ролей не змінюються. `manage_options`, установлення/активація плагінів,
керування користувачами та інші адміністративні права не надаються.
Перевірка `edit_post` для кожної зміни/відкату збережена, як і nonce,
підтвердження резервної копії, блокування та захист від конкурентних правок.

Створення й оновлення схеми при `admin_init` залишається за `manage_options`.
Встановлення/оновлення виконує адміністратор, а редактор користується вже
підготовленим інструментом. Старі журнали й можливість відкату збережені;
для нового очищення після оновлення потрібне нове сканування.

Область очищення, карти замін, списки ID та файли JavaScript не змінюються.

## Перевірка

`tests/editor-access-wordpress.php` — на ізольованій WordPress-БД
`ogo_audit_test` з обома активними плагінами:

- меню, сторінки, AJAX і CSV для редактора;
- застосування/відкат статті іншого автора;
- відмова за індивідуальним `edit_post`;
- відмова автору, учаснику, підписнику й гостю;
- nonce та збереження стандартних прав ролі;
- доступ адміністратора після оновлення.

```sh
OGO_TEST_WP_ROOT=/path/to/test-wordpress php tests/editor-access-wordpress.php
```
