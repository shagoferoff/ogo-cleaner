# Ревізія старих посилань — 1.23.0

Режим `audit` лише складає звіт. Він не викликає зміни статей, очищення,
відкат або HTTP-запити й не копіює повний post_content до журналу.
Дані зберігаються в окремій таблиці `${wpdb->prefix}ogo_link_audit`.
Попередні режими та їхній журнал залишаються окремими.

## Сфера перевірки

- Посилання a[href] у post_content: post, page, rivnenschina, dovidka, phogo, press.
- Статуси: publish, private, draft, pending, future.
- Власні домени: ogo.ua, ogo.rv.ua та їхні піддомени, включно з www.
- Відносні адреси визначаються від permalink матеріалу.
- Ігноруються сторонні домени, javascript/mailto, локальні якорі,
  коментарі, script/style/textarea/pre/code, голі URL та інші атрибути.
- Меню, віджети, метаполя, ревізії, вкладення та кошик не перевіряються.
- Некоректні URL, адреси з логіном/паролем та неоднозначні дублікати href
  пропускаються; це інвентаризація читабельних HTML-посилань, не валідатор HTML.

## Групи

1. Активні рубрики: лише /rubrics/view/<slug> на основному ogo.ua, де slug —
   exclusive, life, nadzvychaini, region, opytuvannya, consumer, top, ukraine,
   foto-dnya. Допускаються кінцевий слеш і числова пагінація.
2. Відомі заміни: наявні карти регіонів, Жіночого клубу, гороскопа, дому,
   саду/городу, домашніх тварин і точні відповідники досьє.
3. Невідомі рубрики: адреси з /rubrics/view/ без активного статусу чи карти.
4. Старі адреси статей: /articles/view/ і шаблони /проєкт/дата/ID.html.
   ID не перевіряється через базу під час ревізії — це наступний крок.
5. Інші внутрішні адреси: решта; їх не оголошено непрацюючими.

Відомий відповідник — пропозиція, а не гарантія доступності або готовності
до масової заміни. Якщо пагінація потребує розширення старого правила,
це окремо зазначається. Активні рубрики не успадковуються старими підпроєктами.

## Звіт

Один рядок групує протокол, www, кінцевий слеш, фрагменти та числові сторінки
рубрики. Головні woman/page:N групуються з /woman. Параметри інших сторінок
зберігаються, щоб /?p=1 та /?p=2 не злилися. Оригінальні href, їхні варіанти,
кількість входжень і матеріали зберігаються окремо. Сума матеріалів між
групами може перевищувати загальну кількість — один запис має різні посилання.

У звіті є фільтр, пагінація, деталі групи та посилання на редагування джерел.
Зведений CSV містить групи, категорії, посилання, матеріали, варіанти та
пропозиції. Докладний CSV містить оригінальний href, визначену адресу,
кількість у матеріалі, ID, заголовок і посилання на редагування. CSV
підтримує українську (UTF-8 BOM); небезпечні формули нейтралізуються.
Експорт читає узгоджений знімок звіту, навіть якщо сканування ще триває.
Часткові звіти позначені; заголовки й посилання на редагування джерел
отримуються на момент перегляду/експорту. Звіт — не жива синхронізація статей.

## Виконання

Пакети по 50 записів; зберігаються межа ID, курсор і кількість перевірених
матеріалів. Межа ID фіксується на початку. Після закриття вкладки можна
продовжити поточний запуск; для змінених або нових статей почніть новий.
Перезапис рядків одного матеріалу транзакційний та ідемпотентний. Операції
використовують спільне блокування з очищенням. Результати й історія запусків
зберігаються, поки плагін увімкнено або вимкнено; автоматичного видалення немає.

Для створення таблиці потрібні права CREATE/ALTER і InnoDB. Доступ до звіту,
сканування та CSV — лише edit_others_posts (адміністратор/редактор); AJAX та експорт перевіряють nonce.
Навіть вручну надіслані apply/restore для audit відхиляються. Таблиці звіту
й options змінюються, але wp_posts та старий журнал очищень не переписуються.

## Перевірки

- Чисті PHP-тести: класифікація, точний whitelist, групування, відносні URL,
  сторонні домени, захищені фрагменти, повтори, оригінальні href та CSV.
- JavaScript: початок, продовження, зупинка, застарілий запуск і помилка мережі.
- Ізольовані WordPress 6.8.3 / MariaDB 11.8: dbDelta, інший префікс qa_,
  ONLY_FULL_GROUP_BY, пакет 50, продовження, replay, rollback при помилці
  INSERT, історія, read-only UI, права й nonce, реальні CSV endpoints, узгоджений експорт 511 груп / 837 рядків джерел
  без пропусків на межі 500, межа ID для нових матеріалів.
- Знімок усіх записів до/після підтверджує незмінність текстів, заголовків,
  статусів і дат. Перевірки не виконувалися на робочому сайті ОГО.
