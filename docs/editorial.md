# Погоджені рубрики — в теги (1.24.0)

Операція `editorial_urls` додає точні відповідники редакції та правило
для старих рейтингів. Повний список 34 рубрик із наданого звіту, цілі
й кількість входжень: [editorial-map.csv](editorial-map.csv). Сума — 123
входження. Це покриття адрес зі зведеного експорту, а не підтвердження
застосування змін на сайті: готовність конкретних HTML-посилань визначить
нове сканування й попередній перегляд.

Рецепти газети → reczepty; підсумки 2011 → pidsumky-roku; рейтинги → rejtyngy;
оборона → oborona; Волинь → volyn; Європа → yevropa; Євро-2012 →
chempionat-yevropy-z-futbolu; довідка → dovidka; один день → odyn-den;
policy → polityka; нові обличчя → novi-oblychchya-rivnogo; вибори → vybory;
бізнес → biznes; agro → agrovyrobnyky; гороскоп газети → goroskop;
vlada → vlada; people-handmade → rukodillya.

Для policy початковий підпис посилання й адреса розходилися. Редакція
обрала перший запропонований варіант — https://ogo.ua/tag/polityka/.

## Рейтинги й активні рубрики

Для головного `/rubrics/view/<slug>` токен top (на початку назви або після
дефіса/підкреслення, із закінченням, роздільником чи числом) або influence
дає тег rejtyngy. Це охоплює top-publicservant зі звіту та подібні старі
рейтинги. Точне ім'я top виключене: активна рубрика `/rubrics/view/top/`,
включно з пагінацією, не змінюється. Desktop/topology не є такими токенами.
Окремий точний відповідник ogo20 теж веде на rejtyngy. Рейтингове правило
не поширюється довільно на підпроєкти; для них є лише погоджені точні пари.

Перевірки захищають усі дев'ять активних рубрик та їхні сторінки. Карта
ревізії використовує той самий resolver; whitelist активних перевіряється
раніше за відомі заміни. Стара ревізія залишається незмінним знімком —
новий список категорій з'явиться після нової ревізії.

## Застосування

Підтримуються http/https, www, //, адреси від кореня, кінцеві слеші та
числові `/page:N`. Номер сторінки не переноситься. Змінюються лише байти
href; текст, розмітка та інші атрибути зберігаються. Параметри й якорі
залишаються, крім #page-top на замінюваних адресах. Пошкоджені або
неоднозначні посилання й непідтримані суфікси — на ручну перевірку.
Матеріали з необробленими збігами не отримують статус готових для масової
заміни. Використовуються наявні журнал, контроль змін матеріалу й відкат.

Після встановлення оберіть «Погоджені рубрики — в теги», почніть нове
сканування та перевірте «Було → стане». Спочатку застосуйте до вибраних
матеріалів. Після завершення запустіть нову ревізію та експортуйте залишки.

## Перевірки

227 функціональних випадків: точні пари, рейтингові шаблони, пагінація,
різні форми URL, узгодженість із ревізією, усі дев'ять активних рубрик,
захищені фрагменти й неоднозначні посилання. Окремо перевірено всі
34 групи (123 входження) з наданого зведеного CSV.

У локальному WordPress 6.8.3 / MariaDB виконано сканування, збереження
попереднього перегляду, застосування, пропуск матеріалів для перевірки,
точний відкат і захист від правок після сканування. Активна /top/
залишається незмінною й після застосування. Робочий сайт тут не змінювався.
