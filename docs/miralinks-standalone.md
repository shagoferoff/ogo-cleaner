# OGO Miralinks Audit 1.0.0

Окремий вузький плагін для поточного етапу: read-only ревізія зовнішніх
посилань у 2215 статтях із видимих аркушів Excel. Архів містить тільки
`ogo-miralinks-audit/`. Основний OGO cleaner не змінено.

Користувач повідомив про Defender Trojan:Script/Ulthar.A!ml у `assets/admin.js`
OGO cleaner. Порівняння 1.26.1, 1.27.0 і 1.27.1 показало побайтову тотожність
цього файла; причина виявлення і статус хибного спрацювання не підтверджені.
Скрипт належить режимам очищення, не використовується ревізією. Виділення
потрібної функції в окремий плагін прибирає залежність від усіх цих режимів,
їхніх класів і адміністративного скрипту. Файл не перейменовано і не приховано:
його функціональності у цьому пакеті немає. Антивірусний висновок щодо нового
пакета не заявляється.

Ревізія походить із `includes/external.php` версії 1.27.1; парсер і список ID
збігаються за поведінкою. Підтримується та сама область, статуси, транзакційні
рядки матеріалу, історія, keyset CSV, захист CSV-формул, caps/nonce та відмова
від apply/restore. `anons` не сканується. Див. [опис ревізії](external.md).

Власні класи OGO_MLA_*, таблиця `$wpdb->prefix.'ogo_miralinks_audit'`, параметри
`ogo_mla_*`, AJAX `ogo_mla`, експорт `ogo_mla_export`, сторінка
`tools.php?page=ogo-miralinks-audit`. Спільний `ogo_mc_lock` запобігає одночасним
операціям із OGO cleaner. Спільних класів, таблиць результатів або залежностей
від основного плагіна немає. Старі журнали залишаються у старому плагіні.

Встановлення як нового плагіна; Інструменти → OGO Miralinks Audit → Нова ревізія.
Після завершення передати CSV «статті, адреси й анкори» для визначення реклами.

Перевірки:

```sh
php tests/miralinks.php
node tests/miralinks-js.cjs
OGO_TEST_WP_ROOT=/isolated/wordpress php tests/miralinks-wordpress.php
```

Інтеграційний тест потребує лише цього активного плагіна в ізольованій БД
`ogo_audit_test`, адміністратора audit_admin та заблокованих зовнішніх HTTP.
Перевіряє незмінність posts/postmeta, зупинку/відновлення, границі списку,
права/nonce, транзакційний збій, ключі багатопорційного експорту та застарілі
списки. Сумісність із одночасно активним OGO cleaner перевіряється окремо.
