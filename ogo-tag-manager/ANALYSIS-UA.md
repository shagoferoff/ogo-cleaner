# OGO Tag Manager 3.8.0

Перші два сценарії реалізовано: однина → множина та масова транслітерація кириличних slug. Нова головна сторінка, послідовні запити, перевірки й автоматичні 301. Старі позначки залишаються для ручного видалення.

Докладні інструкції, межі застосування і результати перевірок — у README-UA.txt. Вихідний аналіз 3.7.0 збережений у попередньому коміті.

Перевірено синтаксис PHP і JavaScript, 36 ізольованих сценаріїв PHP та 16 браузерних/HTTP-сценаріїв. Тестові API WordPress і база позначок — штучні; справжній WordPress/MySQL і плагіни сайту локально не запускалися.
