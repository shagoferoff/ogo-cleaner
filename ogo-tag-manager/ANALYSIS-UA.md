# OGO Tag Manager 3.9.0

Нова головна сторінка охоплює весь цикл: знайти наявні пари → перенести статті й увімкнути 301 → масово видалити перевірені джерела. У розділі 3 всі придатні джерела вибрані автоматично; перед видаленням показано кількість і попередження про незворотність. Підтримуються вже виконані перенесення 3.8.x без їх повторного запуску.

Додавання нових позначок не виконується. Кнопка CSV є вгорі й біля списку правил.

Операції видалення мають підписаний відбиток плану, свіжу перевірку зв’язків, прав, SEO й активного редиректу. Журнал наміру зберігається перед викликом wp_delete_term. Після видалення лишаються цільові зв’язки, staged-записи та правила 301. Є продовження після часткових помилок і зупинка при неоднозначному мережевому збої.

Перевірено 36 попередніх і 31 новий PHP-сценарій, 16 попередніх і 14 нових браузерних/HTTP-сценаріїв. Це ізольовані замінники API WordPress зі справжніми PHP/JS плагіна; справжній WordPress/MySQL і сторонні плагіни сайту локально не запускалися. Деталі — README-UA.txt.
